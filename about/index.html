About

A small tool for a tender family moment.

MythicalHelper exists for the day a child starts asking who carried the magic behind Santa, the Tooth Fairy, Easter, or another family tradition.

What it does

Parents can create a printable certificate naming a trusted helper, select the realms their household served, and print a keepsake with a QR code that opens a public verification record.

What it is not

It is not a paid template shop, an advertising funnel, or a tool for pressuring children to keep believing. It is a way to make hidden care visible when a family is ready for that conversation.

Why open source

The project is open source so the tone, privacy behavior, accessibility, and family-facing language can be inspected and improved in public.

See the project

Try the demo record, create a certificate, or review the source on GitHub.
