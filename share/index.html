Open Source

Developer community

MythicalHelper is a small open-source nonprofit web project built with static pages, Cloudflare Workers, and D1. It helps parents create printable, verifiable certificates for preserving childhood wonder with care. Contributions around copy, accessibility, privacy, and internationalization are welcome.
