Privacy

Privacy notes for a family-facing project

MythicalHelper is a free, open-source, nonprofit project. It is designed to collect only what is needed to create and retrieve a certificate record.

What a certificate record stores

The current record flow stores an email address, the helper name that should appear on the certificate, the watched name or names entered by the parent, selected realms, issue date, access token, verification token, and record status.

Why an email is used

The email is used to create one household record and to send a return link so the record can be reopened, revised, or deleted. It is not used for advertising or mailing lists.

What appears publicly

The public verification page can show the helper name, watched names, selected realms, issue date, and status for anyone who has the verification link or scans the QR code. Do not enter full legal names if nicknames are more appropriate for your family.

Deletion

When a record is open in edit mode, the Access page includes a delete action. Deleting the record removes it from the active database.

Analytics and advertising

The project does not include ad tracking in the repository. If analytics are added later, they should be privacy-friendly and documented here.

Open source

The source code is public on GitHub so privacy-sensitive behavior can be inspected, discussed, and improved.
